版本 v3.1.0(2026-10-25)· 单 Flask 应用:前台页面(HTML)+ /api/*(JSON)+ /admin(后台)· 本文档覆盖全部 ~80 个 HTTP 端点

0全局约定(AI 必读)

Base URL

环境地址说明
本地开发http://127.0.0.1:5100Flask 直出;MYSITE_COOKIE_SECURE=0 时 HTTP 可用 cookie
生产https://imyxj.xyznginx 反代到本机 5100;页面/接口同域

认证

  • 登录:POST /admin/login(表单,非 JSON),成功后种 session cookie。Secure; HttpOnly; SameSite=Lax,默认 7 天。
  • 标 需登录 的接口:未带有效 cookie → API 返回 401 {"error":"..."},页面重定向到登录。
  • 可选 2FA(TOTP):启用后登录表单需多带 totp 字段。

写保护与请求限制

  • Origin 校验:所有 POST/PUT/DELETE 带 Origin 头时必须同源(localhost 开发除外),否则 403 {"error":"非法来源..."}。服务端工具(curl 无 Origin)不受影响。
  • JSON 请求体 ≤64KB;例外:/api/upload 与 /api/doodles(multipart)。全局上限 8MB。
  • 客户端 IP:仅信任 nginx 覆盖后的 X-Forwarded-For(生产);直连开发取 remote_addr。

响应与时间

  • 成功:{"ok": true, ...} 或直接返回数据对象;失败:{"error": "中文原因"} 或 {"ok": false, "error": "..."}。
  • 删除类常用 204 空体;新建类常用 201 + 整行数据。
  • 时间一律 unix 秒级时间戳(例外:导出 JSON 里 exported_at 是 ISO8601)。
  • 文本字段的非法值会被服务端收敛(截断/回退默认)而不是报错;结构错误(传对象给字符串字段)返回 400。

公开写接口限频(进程内,重启清零)

5认证

GET/admin/login

登录页 HTML。已登录则 302 到 /admin/。是否需要验证码看安全设置 sec_captcha。

GET/admin/captcha.svg

生成新图形验证码(SVG,字符以 <text> 渲染),答案摘要写进 session;一次性,提交登录即作废;3~6 位(设置可调);3 分钟有效。

POST/admin/login

表单编码(application/x-www-form-urlencoded,不是 JSON)

字段必填说明
password是后台密码(PBKDF2 校验)
captcha视设置验证码答案;sec_captcha=1 时必填
totp视设置6 位动态码;启用 2FA 后必填

失败重定向回登录页(flash 提示)并记失败次数;连续失败触发 IP 封锁 + 登录时延。成功重置 session 并 302 到 /admin/。

GET/admin/logout

登出并清 session,302 回登录页。

8 类内容同一套调用模式

统一模式(kind = skills / timeline / stats / works / profile / honors / notes / friendlinks):

  • POST /api/{kind} → JSON 字段 → 201 返回新建整行
  • PUT /api/{kind}/{id} → 只覆盖请求里出现的字段 → 200 返回更新后整行;id 不存在 404 {"error":"not found"}
  • DELETE /api/{kind}/{id} → 成功 204 空体;不存在 404
  • 非法值收敛:枚举回退默认、数字夹取范围、文本截断(见 §0);列表读走 GET /api/content 或对应 /api/page/*
kind字段(类型 · 约束)
skillsname(str) · percent(int 0-100) · note(str) · category(serious|passive) · color(teal|pink|yellow|purple|blue|orange) · sort(int,小在前)
timelineemoji · time_label(str,自由文本如 "2026.09"/"现在") · title · content · sort
statsemoji · number(int) · unit(str) · label · sort
worksemoji · cover(pink|yellow|teal|purple|orange|blue) · title · desc · pill(状态小标签) · link(URL,空不显示) · sort
profilekind(about|info:about=自我介绍段落 / info=信息卡片) · emoji · label · value · sort
honorsemoji · year(str) · title · desc · level(national|provincial|school|other) · sort
notesemoji · text(≤80 字) · mood(teal|pink|yellow|purple|blue|orange) · ts(unix 秒,默认现在) · sort
friendlinksname · url · emoji · desc · sort

POST/api/songs · PUT/api/songs/{id} · DELETE/api/songs/{id}

音乐与上面同模式,但有歌曲 ID 自动解析

字段:title(必填)、artist、emoji、note、sort,以及二选一的 song_id(QQ 音乐数字 id)/ link 或 song_mid(QQ 分享链接,服务端自动换算成数字 song_id)。

// POST 400 {"error":"没认出歌曲:贴 QQ 音乐分享链接(带 songid 或 songmid 都行)"}

multipart,字段 file

GET/api/uploads · DELETE/api/uploads/{name}

GET 列出 uploads 目录图片:{"items":[{"name","url","size","mtime"}]}(新的在前)。DELETE 只允许纯文件名(防穿越),成功 204。

相册 = 给已上传文件挂元信息;文件本身走 /api/upload
